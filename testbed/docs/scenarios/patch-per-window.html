stats channel · stats subgraph

statsUpdates(matchId)

Changes
~20 plays/s, bursts of 200/s
Frame
one every 500 ms: DELTA (final values of what changed) or STATE (full state), whichever is smaller; CHECKPOINT every 1 s
Rule
applies a DELTA if from ≤ local version < version; otherwise, asks for a snapshot with a minimum version
History
does not exist: recovery is always a snapshot
query · cache 2 s / 60 s
scoreboard(matchId, minVersion)

"A consistent scoreboard at some version ≥ minVersion." With 0, it is the shared key for the immediate render.

query · cache 5 s / 60 s
matchStats(matchId, minVersion)

Same contract. With minVersion = v coming from the stream, it is a new key that no old response satisfies.
