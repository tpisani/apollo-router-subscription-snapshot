Retaining the last state across several instances

How each client reaches the current state when every frame carries the full state and each Router instance (here, the edge that emulates the plugin) keeps the last frame of each deduplicated subscription. There are several instances behind a balancer, without session affinity. Click a step to see the client's state and the retained frame, or use Play.
